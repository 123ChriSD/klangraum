# KLANGRAUM

Formen, die klingen – Browser-Musik-App mit 3D-Klangformen, Loopstation, Beatbox und echten Instrumenten.

**Starten:** https://123chrisd.github.io/klangraum/

Auf dieser eigenen https-Adresse funktioniert das Mikrofon direkt (Loopstation, Gesang, Mikro → Form). Auf dem Handy: Chrome-Menü ⋮ → „Zum Startbildschirm hinzufügen“ – dann startet KLANGRAUM wie eine App im Vollbild.

Instrumenten-Aufnahmen im Ordner `s/`: tonejs-instruments (Nicholaus Brosowsky), CC-BY 3.0 – Quellen in `s/QUELLEN.txt`.

## Entwicklung
- `docs/` – Projektgedächtnis (Stand, Architektur, Hilfe, Bedienkonzept)
- `src/` – Module je Version und Bauskripte
- `tools/` – Prüfstand, Layout-Prüfung, Ende-zu-Ende-Tests, Website-Bau (`mksite.py`)
- `CLAUDE.md` – Arbeitsregeln
